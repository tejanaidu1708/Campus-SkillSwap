# Campus SkillSwap

### A Student Skill Exchange Platform

Campus SkillSwap is a web application that helps college students
teach skills they already know and learn new skills from fellow students.

## Features

- Student registration and login
- Student profile management
- Add and remove teaching and learning skills
- Find other students
- Mutual skill matching
- Send skill-exchange requests
- Accept or reject requests

## Technologies Used

### Frontend
- React.js
- JavaScript
- Axios
- Vite

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Maven
- REST APIs

### Database
- MySQL

## Application Workflow

1. Students register and log in.
2. Students add the skills they can teach.
3. Students select the skills they want to learn.
4. The matching service identifies compatible students.
5. Students send skill-exchange requests.
6. Recipients accept or reject requests.

## Project Structure

- `frontend/` - React user interface
- `backend/` - Spring Boot REST API
- `.gitignore` - Excludes generated and unnecessary files

## Running the Project

### Backend
Configure the MySQL database and the required environment variables,
then run the Spring Boot application.

### Frontend
Install the Node.js dependencies and start the Vite development server.

## Purpose

The goal of Campus SkillSwap is to encourage peer-to-peer learning
within a college community.
